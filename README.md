# Царские конюшни — пробная страница

Статическая адаптивная страница-визитка в стиле барокко для конного клуба «Царские конюшни» (Владивосток). Работает на GitHub Pages без платного хостинга, сборки, фреймворков и сторонних библиотек.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `tsarskie-konyushni`.
2. Загрузите в **корень** репозитория `index.html` и папку `assets` из этого архива. `README.md` — необязательный.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, сохраните настройки.
5. Сайт откроется по ссылке `https://ВАШ_ЛОГИН.github.io/tsarskie-konyushni/` после публикации GitHub Pages.

## Где изменить контакты

В конце файла `index.html` найдите объект `SETTINGS`:

```js
const SETTINGS = {
  telegram: 'https://t.me/your_club',
  whatsapp: 'https://wa.me/79991234567',
  phone: '+79991234567',
  instagram: 'https://www.instagram.com/your_club/',
  maps: 'https://yandex.ru/maps/...'
};
```

В скачанной странице **все значения изначально пустые**. Поэтому демонстрационные кнопки показывают уведомление вместо перехода по выдуманной ссылке. После подстановки реальных данных заработают переходы в мессенджеры, звонок, Instagram и карта.

## Где изменить услуги и цены

В том же файле найдите `const SERVICES = { ... }`. Там лежат тексты шести всплывающих карточек, включая прайс и адрес. Перед реальной публикацией проверьте описание занятий, ограничения для детей, условия прогулок и тарифы.

В CSS в начале `index.html` можно легко поменять основные цвета (`--bg`, `--panel`, `--gold`). Картинка логотипа находится в `assets/logo.webp`.

## Важно

Это **прототип**, а не реальная система онлайн-записи. Кнопка записи может вести на Telegram/WhatsApp/телефон; формы записи с отправкой данных на сервер здесь нет. Все изображения находятся в папке `assets`, поэтому страница загружается без сторонних сервисов.
